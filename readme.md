# Балансировщик для отказоустойчивого WordPress

WordPress предусматривает горизонтальное масштабирование - при использовании внешних хранилищ для файлов и внешних БД можно запустить несколько инстансов WordPress, но перед ними нужен балансировщик. Итого получается два каскада из серверов Angie:
1. front - фильтрует трафик и обеспечивает распределение трафика на хосты с динамичным и статичным контентом
2. back-static - web-сервер со статичным контентом
3. back-dynamic - web-серврер с динамичным содержимым

## front

Обратные прокси с настроенными фильтрами и ограничениями для непосредственного подключения пользователей.

## back-static

Простой web-сервер со статичным содержимым WordPress. Статичное содержимое формируется движком WordPress хостов `back-dynamic` в общем отказоустойчивом/распределённом хранилище, а хосты `back-static` его только читают.

## back-dynamic

Хосты с Angie в режиме fastCGI-proxy к движку WordPress
